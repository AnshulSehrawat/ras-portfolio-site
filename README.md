# RA.S — Anshul Sehrawat's site

Plain HTML/CSS/JS, no build step. GSAP + Lenis are vendored in `vendor/`, fonts self-hosted in `fonts/`.

Run it:

    cd ~/WORK/PORTFOLIO_SITE && python3 -m http.server 4317 --bind 127.0.0.1
    open http://127.0.0.1:4317/          (combined)   /ecom.html   /art.html

- `js/content/cuts.js` — the three sites are one list of blocks each. Reorder or cut there.
- `js/content/site.js` — facts, contact, clients, services (from the CV). Testimonials/results stay hidden while empty.
- `js/content/media.js` — generated by `python3 tools/build_media.py` from `~/WORK/personal website/assets`.
- `js/content/logos.js` — the owner's RA.S marks, traced from `assets/logo sheet.psd`.
- `js/sections/<id>.js` + `css/<id>.css` — one patch each. `?only=<id>` shows one patch alone.
- `media/tex/` — procedural paper textures (`python3 tools/build_textures.py`).
- `js/content/previews.js` + `media/**/*.avif` — `python3 tools/build_previews.py` after any media change: AVIF copies
  and a tiny blurred preview + tone per photo. `js/core/imgload.js` shows the preview under every image until the photo
  is in, starts lazy images 1600px early and fetches the rest when the page is idle, so no image is ever an empty box.

Note: ad images live in `media/statics/`, never a folder named "ads" - ad blockers block any URL with `/ads/` in it.
